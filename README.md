# INDIAX website

Static website (plain HTML, CSS and JavaScript). No build step.

## Pages
index, services, process, case-studies (+ 2 case study pages), global, blog (+ 6 articles), contact, 404.

## Before going live
1. Replace `YOUR-DOMAIN.com` in `sitemap.xml` and `robots.txt` with your real domain.
2. Check every `CONFIRM` / `TODO` comment in the HTML (search the project for these words).
3. Connect the contact forms to a real form service (they currently open the visitor's email app).

## Deploy
Cloudflare Pages: connect this repository, build command blank, output directory `/`.
